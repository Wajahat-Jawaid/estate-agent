# Zameen AI — Project Context

## What This Is

An AI-powered real estate property search assistant for Karachi, Pakistan. Users can search for properties in natural language (English or Urdu) via two channels:

- **Web chat UI** — a browser-based chat interface served by the FastAPI backend
- **WhatsApp** — a Meta Cloud API webhook that sends property image cards, formatted captions, and interactive reply buttons

The bot understands Pakistani property terminology (DHA, Clifton, crore/lac pricing), maintains per-user conversation memory, and can handle follow-up queries ("show me cheaper ones", "which has the most bedrooms?").

---

## Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | FastAPI (Python) |
| **LLM** | Groq API — `llama-3.3-70b-versatile` |
| **Embeddings** | HuggingFace `sentence-transformers/all-MiniLM-L6-v2` |
| **Vector DB** | ChromaDB (local, persisted to `chroma_db/`) |
| **Conversation memory** | LangChain `ConversationBufferMemory` (in-process, per user ID) |
| **WhatsApp** | Meta Cloud API (webhooks via ngrok tunnel) |
| **SMS fallback** | Twilio credentials present but commented out |
| **Frontend** | Vanilla HTML/CSS/JS (`static/index.html`) — Playfair Display + DM Sans |

---

## Data

- **500 synthetic listings** in `data/listings.json` — 100 original + 400 generated by `generate_listings.py`
- Covers: houses, apartments, upper/lower portions, penthouses, farmhouses
- Locations: DHA, Clifton, Bahria Town, Gulshan-e-Iqbal, PECHS, North Nazimabad, Gulistan-e-Johar, FB Area, and ~30 more Karachi areas
- Price range: ~18 lac (Baldia Town portions) to ~12 crore (Emaar penthouses)
- Each listing has: price, bedrooms, bathrooms, area (sq yd), features, agent name + phone, and image URLs (from picsum.photos)
- `data/welcomed_users.json` — persists which WhatsApp numbers have received the welcome message across server restarts

## Key Files

| File | Purpose |
|---|---|
| `main.py` | FastAPI app — `/chat` (web), `/whatsapp` (Meta webhook), `/reset`, `/health` |
| `agent.py` | Core AI logic — query classification, filter extraction, ChromaDB search, LLM response generation |
| `ingest.py` | One-time script to embed all listings into ChromaDB |
| `generate_listings.py` | Generates the 400 synthetic listings and patches image URLs onto existing 100 |
| `fetch_images.py` | Utility for image handling |
| `static/index.html` | Full single-file web chat frontend |

## Current Status

**Working:**
- Web chat UI — search, follow-ups, filter extraction, property cards
- WhatsApp integration via Meta Cloud API — image cards, captions, interactive buttons
- Multi-turn conversation with per-user memory (search history, follow-up classification)
- Action shortcuts: "4" = cheaper, "5" = larger, "6" = agent contacts
- Welcome message sent once per new WhatsApp user (persisted to disk)
- Session reset via keywords ("reset", "start over") or Reset button
- Bilingual support (English + Urdu responses)
- ngrok tunnel for local WhatsApp webhook development
